# telecom-forensics-playbook
A hands-on 5G core network lab (Open5GS + UERANSIM) documenting forensic evidence and log signatures for telecom security incidents and attack scenarios.
Each scenario in `scenarios/` documents a specific attack or failure condition, how to reproduce it, the resulting log evidence from the core network, and analysis of what a SOC analyst should look for and do when encountering that pattern in production.

## Structure
- `configs/` — Open5GS and UERANSIM configuration files used in this lab
- `scenarios/` — individual documented forensic scenarios
- `screenshots/` — supporting visual evidence for key scenarios
